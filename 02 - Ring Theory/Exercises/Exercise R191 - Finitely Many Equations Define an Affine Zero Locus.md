# Exercise R191: Finitely Many Equations Define an Affine Zero Locus

## Problem Statement

> [!question] Exercise 6.1
> Let $V\subset\mathbb C^n$ be the locus of common zeros of an infinite set of polynomials $f_1,f_2,f_3,\ldots$. Prove that there is a finite subset of these polynomials whose zeros define the same locus.

## Hints

> [!hint]- Hint 1
> Form the ideal generated by all the $f_i$ and use the Hilbert Basis Theorem.

## Solution

> [!success]- Solution
> Let
>
> $$
> I=(f_1,f_2,f_3,\ldots)\subseteq\mathbb C[x_1,\ldots,x_n].
> $$
>
> By the Hilbert Basis Theorem, the polynomial ring is Noetherian, so $I$ is finitely generated. Because $I$ was generated by the displayed family, some finite subfamily $f_{i_1},\ldots,f_{i_r}$ already generates it.
>
> A point annihilates every $f_i$ exactly when it annihilates every element of $I$, and this happens exactly when it annihilates the finite generating subfamily. Therefore
>
> $$
> \boxed{V(f_1,f_2,\ldots)=V(f_{i_1},\ldots,f_{i_r}).}
> $$
