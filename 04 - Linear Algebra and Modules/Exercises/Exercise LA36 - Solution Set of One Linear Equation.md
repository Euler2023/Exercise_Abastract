# Exercise LA36: Solution Set of One Linear Equation

## Problem Statement

> [!question] Exercise 2.3
> Find all solutions of $x_1+x_2+2x_3-x_4=3$.

## Hints

> [!hint]- Hint 1
> Choose three variables freely.

## Solution

> [!success]- Solution
> Let $x_2=s$, $x_3=t$, and $x_4=u$. Then
> 
> $$
> x_1=3-s-2t+u.
> $$
> 
> Thus the full solution set is
> 
> $$
> (x_1,x_2,x_3,x_4)=(3-s-2t+u,s,t,u),\qquad s,t,u\in F.
> $$
