# Exercise LA126: Eigenvalues Constrained by Polynomial Identities

## Problem Statement

> [!question] Exercise 5.3
> What complex numbers might be eigenvalues of $T$ if (a) $T^r=I$, or (b) $T^2-5T+6I=0$?

## Hints

> [!hint]- Hint 1
> Apply each operator identity to an eigenvector.

## Solution

> [!success]- Solution
> If $Tv=\lambda v$ with $v\ne0$, then (a) gives $(\lambda^r-1)v=0$, so $\lambda$ is an $r$th root of unity. In (b), $(\lambda^2-5\lambda+6)v=0$, so $(\lambda-2)(\lambda-3)=0$ and $\lambda\in\{2,3\}$.
