# Exercise G311: Finite Cyclic Subgroups of Q Mod Z

## Problem Statement

> [!question] Exercise 42
> Regard $\mathbb Z$ and $\mathbb Q$ as additive groups. Show that $\mathbb Q/\mathbb Z$ is torsion and has exactly one subgroup of order $n$ for every integer $n\ge1$, and that this subgroup is cyclic.

## Hints

> [!hint]- Hint 1
> If an element is killed by $n$, represent it by a rational number whose denominator divides $n$.

## Solution

> [!success]- Solution
> If $q=a/b\in\mathbb Q$, then $b(q+\mathbb Z)=0$, so every element of $\mathbb Q/\mathbb Z$ has finite order. For $n\ge1$, set
>
> $$
> C_n=\frac{\frac1n\mathbb Z}{\mathbb Z}
> =\left\{\frac{k}{n}+\mathbb Z:0\le k<n\right\}.
> $$
>
> This is cyclic of order $n$, generated by $1/n+\mathbb Z$. If $H\le\mathbb Q/\mathbb Z$ has order $n$, Lagrange's theorem gives $nh=0$ for every $h\in H$. Writing $h=q+\mathbb Z$, the condition $nq\in\mathbb Z$ shows $h\in C_n$. Hence $H\subseteq C_n$, and equality follows because both groups have order $n$. Thus $C_n$ is unique.
