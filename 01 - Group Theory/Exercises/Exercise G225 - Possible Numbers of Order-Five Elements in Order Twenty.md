# Exercise G225: Possible Numbers of Order-Five Elements in Order Twenty

## Problem Statement

> [!question] Exercise 7.3
> How many elements of order $5$ might be contained in a group of order $20$?

## Hints

> [!hint]- Hint 1
> Determine $n_5$ by Sylow III.

## Solution

> [!success]- Solution
> The number $n_5$ divides $4$ and is $1$ modulo $5$, so $n_5=1$ or $4$. Distinct order-$5$ subgroups meet only at $1$, and each contributes four elements of order $5$. Hence the possibilities are $4$ and $16$. Both occur: $C_{20}$ has four, while the affine group $C_5\rtimes C_4$ has sixteen. $\square$
