# Exercise G70: Prime-Order Elements in a Group of Order 35

## Problem Statement

> [!question] Exercise 8.4
> Does a group of order $35$ contain an element of order $5$? Of order $7$?

## Hints

> [!hint]- Hint 1
> Apply Cauchy's theorem to each prime divisor of the group order.

## Solution

> [!success]- Solution
> Yes to both. Since
> 
> $$
> 35=5\cdot7,
> $$
> 
> Cauchy's theorem gives an element of order $5$ and an element of order $7$.
> 
> The exact imported input is Cauchy's theorem: if a prime $p$ divides the order of a finite group, then the group contains an element of order $p$.
